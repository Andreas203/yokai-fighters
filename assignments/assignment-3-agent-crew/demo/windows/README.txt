YOKAI FIGHTERS - playable demo (Windows x86_64)

Double-click PLAY.bat (or YokaiFighters.exe) in this folder.

Keep everything in this folder together: YokaiFighters.exe needs
data_YokaiFighters_windows_x86_64\ (.NET assemblies), data\ and fixtures\ beside it.

Cloned the repo? The exe and DLLs are stored with Git LFS. If PLAY.bat says
"LFS pointer", install Git LFS and run:  git lfs pull

No git? Download the zip instead:
https://github.com/Andreas203/yokai-fighters/releases/tag/demo-v0.1

Controls are on the start screen. Beat the Kitsune, draft one of her powers,
then win the rematch.
