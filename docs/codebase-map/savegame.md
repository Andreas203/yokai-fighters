# SaveGame: the save file

`game/scripts/SaveGame/`, namespace `YokaiFighters.SaveGame`. The run in progress, unlocks and story progress (M4) in `user://save.json` (dev mode: `save.dev.json`, see [dev.md](dev.md)). Pure C#, no clock, no randomness: the same data writes the same bytes. The sim never reads it (`Sim/`, `Ai/`, `Replay/` are test-scanned). `Flow/GameFlow.cs` is the only caller ([flow.md](flow.md)). Naming the store in tests is an explicit list in `SaveProbes.Isolation_*` (not a name suffix): `SaveTests` and `SaveProbes` freely; `MerchantShopSaveTests`/`MerchantShopSaveProbes` in memory only (no `new SaveStore(`, `GameFlow` or `SaveStore.FileName`); `PracticeBreakerProbes` with a temp-path `SaveStore` (YOK-204). A new file must be added to that list. Index: [README.md](README.md).

| File | What it is and its public surface |
|---|---|
| `SaveGame/SaveData.cs` | Immutable `SaveData`: `Run` (`RunSave?`), `Unlocks` (ability ids in award order, M1), `Story` (`StoryProgress`: free-form flags `Seen`/`Has`/`With`; `EldersMet`/`HasMetElder`, an id no map names is kept and never matches), `CarryOver` (M3 special id or null), `TanukiWins` (Y5, uncapped, never negative); `WithRun`, `WithUnlock`, `WithStory`, `WithElderMet`, `WithCarryOver`, `WithTanukiWin()` (saturating). |
| (cont.) | `RunSave(Seed, MapId, Visited, Current, Health, Slots)` + `MapFile`, `MapFingerprint`, `Coins`, `CopyLocked`, `LockedCopy`, `FirstMeeting`, `NodePaid`, `OffRoute`; `SlotSave(Slot, Special, Level, Modifier, Levelled, Borrowed, ModifierBorrowed)`, slots are the literal names `A`–`D`. `RunSave.Capture(session, mapFile)`: node boundaries only, refused when the run is over or an offer is open. |
| (cont.) | `Restore(pool, graph, scenes, notes, allowOffRoute)` → a `RunSession` with the same `StateHash`, else `FormatException` with the reason: another or changed map, unknown special / modifier, a slot / level / modifier the rules refuse (A2, A3), health outside 1–1,000, no special at all (A1, T5), a walk the map refuses or one already at the map's end (a won run), a borrowed starter or borrowed modifier with no modifier (R6). Only a bad T3 level-up order is repaired (lower slot = more recent), and it is noted. |
| (cont.) | Also refused (`SaveData.cs`): negative coins (R8), a paid node with no node entered, a `locked_copy` while `copy_locked` is false or missing. |
| (cont.) | Copy lock (T1): a saved `locked_copy` that is not `CopyRule.Target` of the restored slots and level-up order, or a lock that disagrees with the walk, is a `FormatException` (Continue greyed with the reason). **Version-1 rule:** a v1 file saved inside the Tanuki's node (the entry save, slots still those it locked on) has its lock inferred with `CopyRule.Target`, and noted; anything else past the lock point, or a repaired T3 order there, is refused as unrestorable, never guessed. `OffRoute` saves are refused unless `allowOffRoute` (dev mode only). |
| (cont.) | `IsMapFileName(name)` = the path-traversal guard: `map_file` is only ever a bare `.json` file name inside `data/map/` (no directory, rooted path or `..`); anything else greys Continue and the boot still finishes. |
| `SaveGame/SaveStore.cs` | Path injected. JSON `{ version, run, unlocks, story: { seen, elders_met }, carry_over, tanuki_wins }`, `CurrentVersion` 7 (v2 `coins`, `copy_locked`, `locked_copy`; v3 `borrowed`/`modifier_borrowed`; v4 `node_paid`, written only when true; v5 `elders_met`, `first_meeting`; v6 `carry_over`; v7 `tanuki_wins`). `Load()` never throws → `SaveLoad(Data, Status, Problems)`, status Loaded/Missing/Corrupt (empty)/Partial/OlderVersion/NewerVersion. |
| (cont.) | Run, unlocks and story are read separately: a broken run is dropped alone (it needs seed, map, visited, health, slots; other fields default), bad unlock / story entries are skipped, unknown fields ignored. A version that is present but not a whole number ≥ 0 (`"1"`, `1.0`, `2147483648`) is `NewerVersion`, never older. `Save(data)` = temp file flushed to disk + rename; returns false and sets `LastSaveError` when the disk refuses. |
| (cont.) | **Never destroys a file it could not fully read**: after a load where `LostSomething(load)` (every status except Loaded, Missing and a problem-free OlderVersion) the first write copies the file to a free backup name (`save.json.bak`, `.bak.1`, ...; a backup is never replaced); after a read the disk refused (`WriteBlocked`) nothing is written until a later load succeeds. |
| (cont.) | **Adding saved state:** a property with a default on `RunSave` (or a top-level field beside `unlocks`, `story`, `carry_over`, `tanuki_wins`); read it in `SaveStore.Run` with that default (missing = default, no problem); write it in `Serialize`; a format change adds its conversion in `Parse`, keyed on the version; **raise `CurrentVersion`**, so an older build loads the file as `NewerVersion` and backs it up before writing one without the field. |
| `SaveGame/ElderMeetings.cs` | Y3, M4, M5, pure: `ElderOf(node)` = the yokai id of a node with `MapNodeData.Elder` (no hard-coded ids; the Elder Oni on rows 5 and 8 is one elder), `Enter(saved, node, out first)` (the node-entered save point marks the elder met; `first` = not met before this entry), `Resume(saved, session, out first)` (Continue into a node: first when the entry save said `first_meeting` or the elder is not in the file, a v4-or-older save). Not in any `StateHash`. |

## Save points and what is never saved (M5, AM3)

- Save points are node boundaries only: run started, node entered, node completed. Nothing is written during a fight; a run that ends is removed from the file.
- Merchant (R6) and dojo (R7) choices, trials and their attempts are never saved: both save points see them as `None` (`SaveTests.MerchantAndDojoChoices_AreNoneAtEverySavePoint`). A quit mid-trial comes back at the entry save with attempts 0 (`SaveTests.DojoTrial_NothingOfAMidTrialReachesTheFile`: a mid-trial capture is the entry save byte for byte). Shop purchases need no save point: the `NodeCompleted` save writes slots and coins.
- **A save point added inside a node would have to save the merchant and dojo choices** (`Merchant.Choice`, `Dojo.Choice`), or the stop's heal could be taken twice.
- Practice never reaches a save point (`SaveTests.Practice_*`).
