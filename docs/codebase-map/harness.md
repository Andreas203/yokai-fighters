# Harness: whole-run bot

`game/scripts/Harness/`, namespace `YokaiFighters.Harness`. G1/R5. Pure C#, deterministic: a player-side newcomer Kihon bot plays whole first runs through `RunSession` headless; results go to `harness/results/whole-run/` for the Sparring Partner. Every fight is built by `Sim/Run/NodeFight.cs`, the same builder the fight scene uses (Tanuki fights with `TanukiKit`, copy locked on entry, T0/T1). Index: [README.md](README.md).

| File | What it is and its public surface |
|---|---|
| `Harness/BotConfig.cs` | Kind `harness_bot` (`data/harness/newcomer-kihon-bot.json`, all values **proposed**). `BotFightConfig` (reaction frames, cadence, mistake/block/anti-air/`idle_guard_pct`, ranges, plan lengths, neutral weights, `max_fight_ticks` = a safety cap, no round timer: a stopped fight is a stall, not a loss). `BotRunConfig` (route rule, `reward_order`, merchant/dojo plan, `menu_seconds_per_node`, R9). Scheme must be `kihon`. `LoadDefault(dataDir)`, `Parse`. |
| `Harness/BotLevels.cs` | Kind `harness_bot_levels` (`data/harness/bot-levels.json`): each level merged onto the base bot file and parsed by `BotConfig.Parse`. `LoadDefault`, `LoadFile`, `Parse(json, baseJson)`, `levels[name]`, `LevelNames()`. `newcomer` = the base bot unchanged; intermediate/skilled proposed. Tests `BotLevelsTests`. |
| `Harness/NewcomerBot.cs` | `NewcomerBot(cfg, BotKit, seed).Next(AiView now)` → Ryo's raw `FighterInput` (never a slot request). P6: decides from the screen `ReactionFrames` old. Rolls `block_pct` per threat, `idle_guard_pct` per wait plan (0 draws nothing), `anti_air_pct` per jump on its first free tick; Kihon specials (K2/E18); no EX, burst, throw break or crouch guard. `BotKit.From(fighter)`, `BotStats`. Tests `BotIdleGuardTests`. |
| `Harness/RunBot.cs` | Between fights: `ChooseRoute`, `ChooseCard` (by `reward_order`, lowest-slot target), `AtMerchant(session, bought)` (`heal`, `shop` via `MerchantShop`, `heal_if_hurt_else_shop`, `skip`; never releases), `AtDojo` (rest; never the trial). Tests `MerchantShopBotTests`. |
| `Harness/RunHarness.cs` | `HarnessContent.Load(dataDir, fixturesDir, mapFile)` (kits, pool, map, node scenes, profiles, twists; `CheckProfiles()`; `StandingHabits`, `HitLog`, `RawHitLog`). `RunHarness.PlayRun(content, bot, seed, fight?)`, `FightNode`, `NewNodeMatch` (= `NodeFight.NewMatch` + twist, as `FightScene.NewDuel`), `PlayFight`, `PlayBatch(content, bot, baseSeed, runs)`. Records `RunRecord`, `NodeRecord`, `FightRecord` (incl. `Stalled`, `Twist`, `OpponentCopiedSlot`, `Log`). Merchant/dojo nodes are stops, not fights. Tests `RunHarnessTests`, `HarnessTwistTests`. |
| `Harness/FightLog.cs` | Listens to `Match.Hit`/`Throw` and the AI decision log, never feeds back (P6). `Moves[side][moveId]` (`MoveTally`), `ThrowBreaks`, `ThrowClashes`, habit rolls/fired/covered/punished (`PunishWindowHits` 3), opt-in `Raw` lines. Call `AfterAi(ai, tick)` between `Next` and `Step`. `FightLogReport`. Tests `HitLogTests`, `PunishWindowTests`. |
| `Harness/HarnessReport.cs` | Kind `harness_results` v1 JSON: `ToJson`, `Write(batch, dir)` → `<name>-n<N>-s<seed>.json`. `summary` (reach/beat Tanuki vs R5, stalls kept out of denominators, elder twists, arrival health vs R4, damage per duel vs Y4, run length vs R9, copy-locked specials, cards, routes, `moves`, `habits`, `fight_mix`, `levels`) and `runs`. No clock or machine data: same seed and data = same bytes. |

Command (from `game/`): `godot --headless --path . res://tests/run_harness.tscn -- [--runs 200] [--seed 1] [--level newcomer|<level>|all|mixed] [--levels <file>] [--bot <file>] [--out <dir>] [--data <dir>] [--hit-log]`. Default = 200 runs, seed 1, out `harness/results/whole-run/`. `--data` is used by the data merge check.
