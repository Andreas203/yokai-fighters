# Sim: simulation core

`game/scripts/Sim/` (not `Run/`, `Input/`), namespace `YokaiFighters.Sim`. Pure C#, **no Godot types**, integers only: runs headless for tests and the harness, and replays exactly from per-tick inputs. Positions are **centi-units** (`SimConfig.Scale` = 100 per gameplay unit). The only RNG is `SimRng`. Run state is in [sim-run.md](sim-run.md), input parsing in [sim-input.md](sim-input.md). Index: [README.md](README.md).

## The round

| File | What it is and its public surface |
|---|---|
| `Sim/Match.cs` | One round (`partial`). `Step(in1, in2)` = one 1/60 s tick: `HitstopStep` then `WorldStep`. Phases `Fighting → KoSlowMo → Over`. Input per fighter: explicit `Move` > `Special` > `FindThrow` > parsed command; in `Attack`: `TryExUpgrade` else `TryCancel`; then jump > dash > crouch/walk; guard = hold back, grounded (C3, E6). |
| (cont.) | World order: `AdvanceThrows` → per fighter `AdvanceState` + input → `ResolveThrowBreaks` → `ResolvePositions` → `UpdateFacing` (Idle only) → `StepProjectiles` → `StepAftershocks` → `ResolveThrows` → `ResolveHits` → `ResolveProjectiles` → `ResolveAftershocks` → `ApplyDamage` (simultaneous; double KO = draw). |
| (cont.) | Timing: a move started on tick t plays frame n on t+n-1; N stun frames set on tick h hold h+1..h+N, so advantage = stun − (Total − hit frame). KO: inputs are ignored and the world advances every 2nd tick for 30 world frames (E2, V4), then `Over` until `Reset()`. `StateHash()`, `QueueDamage()`, `Resets` (presentation only, not hashed). Events `Hit`, `KnockOut`, `RoundOver`. |
| (cont.) | `ResolvePositions`: screen walls; push boxes and the corner fix only when both fighters are grounded, so jumps cross over; 1-D push, centres at least `PushGap` apart, corners per fighter `CornerLo/Hi(f)`. `ResolveHits`: both sides' active hitboxes vs the other's hurtboxes (mirrored by facing), applied together so trades work; one connect per move; blocked unless a low meets a standing guard; counterhit if the defender was in a move; an air hit stops drift. |
| `Sim/MatchThrows.cs` | Generic throws (C4, E4, E12), `partial Match`. A throw is a kind `throw` move played as an Attack; the defender gets `Thrown` then the standard `Knockdown`; no paired clip. `FindThrow`/`ThrowPressed`: all buttons within `ThrowPressWindow` 3 from the raw `InputBuffer` (K3). `Throwable(d)`: grounded, not invulnerable, Idle/Dash/Attack. `ResolveThrows` (both = `Clash`, one = `Grab`), `ResolveThrowBreaks`, `AdvanceThrows` → `Land` (C5 +6/+3, heavy hitstop). Grab beats a same-frame strike. Event `Throw` (`ThrowEvent`: Grab/Land/Break/Clash). |
| (cont.) | Worked example, press on tick 1: grab tick 6, break window ticks 7–13, lands tick 14 (then 12 hitstop ticks), defender acts 40 world frames later. A Thrown fighter can't burst. A normal started by a throw button and still in startup is cancelled into the throw. |
| `Sim/Match.Meter.cs` | Meter (C5), burst (C6), hitstop (V2). `OnConnect`: attacker +6 hit / +3 blocked (or the move's `meter_gain`), defender +3, cap 300; `HitstopLeft` = max of the connects; event `Impact` (`ImpactEvent`, with `At` = contact point for the hit spark, not hashed). Burst: from `Hitstun` only, once per fight, LP+MP+HP within `BurstPressWindow` → 20 invulnerable ticks, meter 0, `BurstFired`. `TrySpendMeter(i, cost)` / `TrySpendEx(i)`. |
| (cont.) | Hitstop: while `HitstopLeft` > 0 the world does not advance: `Tick` counts, `WorldFrame` holds, inputs still feed the readers, and a burst can fire and end the freeze. A connect on tick h freezes h+1..h+N for both fighters, so advantage = stun − remaining frames still holds. `Connects` skips `Invulnerable` defenders. |
| `Sim/Match.Specials.cs` | `TryStartSpecial(i, slot, ex, precision, buttons)` (EX spends `ex.meter_cost`, else the plain version; precision = damage × (100 + `PrecisionBonusPct`)/100, K1), `TryExUpgrade` (second press within `ExPressWindow`), `TryCancel` (X1–X4: held rule + data window + outcome; X3 once per combo; `successful_throws` only once the throw has landed, not while the defender is still `Thrown`). An empty slot or the projectile limit makes `TryStartSpecial` return false. |
| (cont.) | `Projectiles`, `StepProjectiles` (spawn at the owner's feet; despawn fully off the camera view), `ResolveProjectiles` (passes / absorbs / trade; push follows the projectile, no corner hand-off). Events `SpecialStarted`, `ProjectileChanged`. |
| `Sim/Match.Air.cs` | Jump-in normals (E11, E19). `CanAirAttack(f)`: in `Jump`, airborne, one per jump (`AirAttackUsed`). Facing fixed through a jump. Touchdown during an air normal → `LandAirAttack` → `Landing` (standing hurtbox, no guard, throwable). No cancel, EX upgrade or throw-cancel in the air; not an overhead (E6). |
| `Sim/Match.Aftershock.cs` | `Aftershock` (owner, serial, move, anchor X, Dir, Age): spawned by `StepAftershocks` when the owner's move plays `FirstActive`, anchored where the owner stood; replays the hitboxes `Delay` frames later; `ResolveAftershocks` hits like a projectile, one connect. A move interrupted before its first active frame spawns none. Hashed only once one has existed. Event `AftershockChanged`; `AftershockBoxes(owner)` feeds `DebugBoxes`. Tests `PushBoxAftershockTests`. |
| `Sim/Match.Twists.cs` | Elder twists in the sim (P5, Y2, Y3): `CountSpecialUse` (same special in a row; EX = same), reflect from the `repeat`-th use in `ResolveHits`/`ResolveProjectiles`, `TwistArmourTakes`, `Unbreakable` throws. Event `TwistTriggered`. Twist state hashed only when a fighter holds one. Tests `ElderTwistTests`. |

## Fighters, moves and kits

| File | What it is and its public surface |
|---|---|
| `Sim/Fighter.cs` | Fighter state: X/Y, `Facing` ±1, health, KO, `Moves` by slot, `FighterState` (Idle, Attack, Hitstun, Blockstun, Knockdown, WakeUp, Dash, Jump, Thrown, Burst, Landing), `MoveSlot`/`MoveFrame` (1-based), `StunLeft`, `Guarding`/`Crouching`, `Actionable`, `CurrentMove`, `Input` (`InputReader`), `AirAttackUsed`, `WalkDir` (not hashed). `FighterStates.IsDown()`. `Fnv` hashing; `SimRng` seeded xorshift32 = the only gameplay RNG. |
| `Sim/Fighter.Specials.cs` | `Specials[5]` by `SpecialSlot` (A–D) of `EquippedSpecial(Data, Level, Move, ExMove, ExCost, Defaults)`; `Equip`, `Unequip`, `LevelUp` (A3, cap 3). `Reset` keeps specials and held `CancelRules` (`HoldCancelRule`, X2 max two). In-play: `ActiveMove`, `ActiveBase`, `ActiveSpecial`, `ActiveEx`, `ActivePrecision`, `ActiveConditions`, `ArmourHitsTaken`, `CancelUsed`; per round `SpecialUses[slot]`. `CancelRule` record. All hashed. |
| `Sim/Fighter.Meter.cs` | `Meter`, `BurstUsed`, `Invulnerable`, `TrySpendMeter`. |
| `Sim/Fighter.Copy.cs` | `Fighter.CopiedSlot`: the Tanuki's copied special slot (T1–T6), set by `TanukiKit.Equip`. |
| `Sim/FighterInput.cs` | `InputBits` flags + `FighterInput(Bits, Move)`: one fighter's raw input for one tick (absolute directions, LP MP HP LK MK HK, Kihon `Special`). `Move`: 0 none, n = slot n-1 (`Attack(slot)`), 201–204 special A–D, 205–208 EX (`Special(slot, ex)`). Devices, the AI (P6) and replays produce it. |
| `Sim/FighterData.cs` | Kind `fighter` (`data/fighters/<id>.json`): body numbers no move carries. `PushWidth` (null = `SimConfig.BodyWidth`, E1). `Load(dir, fighter)` (missing = `Default`), `Apply(f)`. Loaded into `Kit.Body`. |
| `Sim/MoveData.cs` | One move's Lv 1 frame data: startup/active/recovery, damage, hitstun/blockstun, pushback, knockdown, low, `Hitboxes`/`Hurtboxes` as `TimedBox(First, Last, Box)` in gameplay units (x toward the opponent). `IsActive`, `TotalFrames`, `AdvantageOnHit/OnBlock`. Normals: `Button`, `Buttons`, `DirectionMask`, `NormalMatch`. Throws: `ThrowButtons`, `Throwboxes`, `BreakWindow`, `BreakPushback`, `IsThrow`, `ThrowMatch`. `Source`. |
| `Sim/MoveData.Specials.cs` | `ProjectileData` (spawn frame, speed, hitbox, hits, lifetime, passes/absorbs, `MaxActive` 1), `InvulnWindow`/`InvulnAt(frame, kind)` (throw invuln read, not applied, E12), `CancelWindow`. |
| `Sim/MoveData.Air.cs` | `MoveData.Air` (normal file `"air": true`), `LandingRecovery` (null = `SimConfig.AirLandingRecovery`, E19). |
| `Sim/MoveData.Impact.cs` | `HitStrength` enum, `Strength`/`Ex`/`MeterOnHit`/`MeterOnBlock`, `ReadImpact` (`frame_data.strength`, else normals by button L/M/H, else medium). |
| `Sim/MoveData.Modifiers.cs` | Generic modifier properties (A10: no code keyed on a modifier id), read by `ReadModifierProperties`: `CounterhitImmune`, `ProjectileInterruptImmune`, `Armour` (`ArmourWindow`), `ThrowInvulnStartup`, `PullOnHit`, `HealPctMaxHealth`, `ProjectileAngleUp`. Variants: `StartVariants` / `ForStart(held)`, `OnHitVariant` / `OnBlockVariant` / `Outcome(blocked)` (picked from `ActiveBase`), `WithOutcomes(f)`. `ReflectProjectile`. Mirrors `tools/validate_data.py`; shared cases in `game/tests/fixtures/modifier-gate/cases.json`. Tests `ModifierEffectTests`. |
| `Sim/MoveData.Aftershock.cs` | `properties.aftershock_delay` (Oni Quake Lv 3, A5). `MoveLoader` rejects < 1, non-integer, or on a move without hitboxes / a throw. |
| `Sim/MoveLoader.cs` | System.Text.Json reader of move files: `levels.1.frame_data` of a special or top-level `frame_data` (normals read `input.button(s)`/`directions`, throws `input.buttons`, `throwboxes`, `break_window`, `pushback.on_break`). `Parse`, `LoadFile`, `LoadDirectory(dir, includeSpecials)` (file-name order = slot order), `KindOf(path)`. `FormatException` on what the sim can't run. All integers via `Effects.WholeInt`. |
| `Sim/SpecialData.cs` | Kind `special`: `Slot`, `ExCost`, Lv 1 frame data, Lv 2 `tuning`, Lv 3 `evolution.changes`, `ex.changes`. `Build(level, ex[, modifier, defaults])` applies effects in order. `SpecialLoader.Parse/LoadFile/LoadDirectory` (builds every level + EX at load). `Effects.Apply` (`add`/`mul_pct`/`set` on a dotted path), `Effects.Vocabulary` (the closed target list, mirrored by `common.schema.json`), `Check`, `Default`, `Whole`/`WholeInt`, `Combine`, `Text`. `Legal`. |
| `Sim/CancelRuleLoader.cs` | Kind `cancel_rule` → `CancelRule`; `LoadDirectory`; rejects unknown or empty `path.on` and `once_per_combo` other than true (X3). Only tests read `data/cancels/` yet. |
| `Sim/Kit.cs` | `Kit.Load(fighter, KitSources)` = one fighter's own kit (owner = each file's `source`; Ryo = normals/throw + starters, A1). Per-kind fallback to its own test fixtures, else Ryo's fixture moves; a yokai never borrows Ryo's specials. `Notes` logs fallbacks. `LoadAs(yokai, body, src)` (a yokai with no fighter on a body's kit), `LoadSpecials`, `Equip`, `EquipSpecials`. `KitSources(...)`, `.Repo(root)`, `.FixturesOnly()`. |
| `Sim/TanukiKit.cs` | T0–T4: `Build(ryoKit, CopyTarget?)` / `Load(src, copy)` = Ryo's normals, throw, air normals, starters at Lv 1 + the copy at `CopyTarget.MoveLevel`, no modifier (T4). `CopyAtFightStart(copyLocked, lockedCopy, run, starters)`. `CopiedSlot` mirrors Ryo's slot; the copy replaces that starter. `KitId` = `"copy_of_ryo"` (node kit in `data/map/node-scenes.json`). `Equip(fighter)`. Tests `TanukiKitTests`, `ReplayTests.TanukiCopiedSpecial_*`. |
| `Sim/ElderTwist.cs` | `ElderTwist(Id, Elder, Effect, Repeat, ArmourHits, LabelKey, Icon, IntroCard, CalloutCard)` from `data/twists/*.json` (`ElderTwistLoader`, `FormatException` names file/field). `TwistEffect`: `ReflectRepeatedSpecial`, `SpecialArmour`, `UnbreakableThrows`. `ElderTwists.ForNode(node)` (elder nodes only, keyed by the node's yokai), `Apply(match, node)` (P2 only). |

## Config and clocks

| File | What it is and its public surface |
|---|---|
| `Sim/SimConfig.cs` | Fight constants record. Stage half-width 1920, `ViewWidth` 1540 (widest camera zoom, AM9), `MaxSeparation` (derived: `ViewWidth` − 2 × model reach, E1), `BodyWidth`, walk speed (C2), max health (C1), KO slow-down (V4), hit fallbacks, counterhit +20% / +6 (C7), `DashFrames` 18 / `JumpFrames` 40 (C2), `JumpY(n)`, `DashStep(n, dist)`, `KnockdownFrames`, `WakeUpFrames`, idle hurtboxes per stance (E5), `ModelFrontReach`/`ModelBackReach`. |
| `Sim/SimConfig.Air.cs` | `AirLandingRecovery` 3 (E19). |
| `Sim/SimConfig.Meter.cs` | Bars, gains, `BurstFrames`, `BurstPressWindow`, `BurstPushback`, hitstop 6/9/12 (+4), `HitstopEnabled`, `ShakeFrames`. |
| `Sim/SimConfig.Specials.cs` | `PrecisionBonusPct` 10 (K1), `ExPressWindow` 3. |
| `Sim/SimConfig.Modifiers.cs` | `PullStepUnits`, `ProjectileAngleUpRisePct`, const `LowHealthPct` 30. |
| `Sim/FixedStepClock.cs` | Integer-microsecond fixed step (F3): `Advance(nowUsec)` returns ticks due, exactly 60 per second; catch-up capped at 8. |
| `Sim/FightCamera.cs` | The sim's integer screen at the widest zoom (walls, projectile despawn), never the presentation camera. Centre = midpoint clamped at `Limit(c)`; `VisibleHalfWidth`, `VisualExtent(c, f)`, `BothInView()`. |
