# Ai: fight AI

`game/scripts/Ai/`, namespace `YokaiFighters.Ai`. Pure C#, deterministic, seeded `SimRng`. Y1/Y2/Y4/P6: P2 plays from a behaviour profile and sees the world only as `AiView` snapshots through a reaction-delay buffer; it never reads input. Index: [README.md](README.md).

| File | What it is and its public surface |
|---|---|
| `Ai/AiView.cs` | `AiView.Capture(match)` = the **only** sim → AI bridge (P6): tick, phase, hitstop, per fighter `FighterView` (position, facing, state, stun left, airborne, health, `MaxHealth`, meter, `BurstUsed`, visible move id/frame/active window/connected, `MoveIsEx`) and `ProjectileView`s; `JumpPunishPct(i)`, `WakeUpFrames`, `BurstFrames`, `LightHitstop`. No input, parser, buffer or `Match` reference (a reflection test enforces it). |
| `Ai/BehaviourProfile.cs` | Kind `profile` loader (`Parse`, `LoadFile`, `LoadDirectory`): reaction tier/frames, aggression bias, preferred range, `Habit` (when → do → chance_pct), behaviours, `tell_cover_pct`, `guard_pct` (`GuardPct`, 0–100), `ExUse(ChancePct, KeepMeter)`, `BurstUse(ChancePct, MinComboHits, MaxHealthPct)` (null = never, E22). `Observation` enum = the schema's on-screen list; `AiAction` (generic, `normal:<id>`, `special:<id>`, `special:copied`), `IsMove`, `IsEvent`. `AiFightTiers.Of(node)` = the E22 fight tier. |
| `Ai/AiLoadout.cs` | The AI fighter's own kit: action → `FighterInput.Attack(slot)` / `Special(slot[, ex])` + frames. `special:copied` → `Fighter.CopiedSlot` (Tanuki only). `TryGetEx`, `TryGetTotalFrames`, `TryGetExFrames`, `Missing(profile)` (callers throw on any), `IsScreenMoveOf(action, moveId)`, `ThrowMoveId`/`ThrowSlot`/`ThrowRequest`, `CanDo(action)` (side-effect free). |
| `Ai/ProfileAi.cs` | The brain. `Next(AiView now)` stores the screen in a ring of `ReactionFrames` and decides from the oldest (Y4, P6). Per tick: burst check (`burst_use`), habit (event triggers roll on the rising edge; standing triggers re-arm every `StandingHabitRearmTicks` 60, proposed; a fired habit is held until its move shows, `HabitPress`; `tell_cover_pct`; `self_got_up` pre-holds to the wake tick), event behaviours (percent per occurrence), then neutral weighted pick (offence × (50 + aggression)/100, defence × (150 − aggression)/100, `SpacingWeight` 40). |
| (cont.) | Bands close < 250, mid < 600 (proposed). |
| (cont.) | E22: ctor `tier` (`AiFightTier` Standard/Elder/Tanuki); `ex_use`/`burst_use` roll only in elder and Tanuki fights (`MaybeEx`, `Burst`). Pre-emptive guard `GuardPct` (`RollGuard`, `GuardTicks` 10, follows cross-ups; `ExtendGuard` through hitstop). Jump punish by tier (`JumpPunish`): one draw at `JumpPunishPct(Self)`, then a weighted pick among answers `CanDo` allows, held to `FirstActionableTick`, window capped at `MinInterruptTicks`. Ctor `standingHabits` false = pre-YOK-177 rule for old replays. `HabitPlanRunning`, `Log` (`AiDecision`s). |
| `Ai/NodeTemperament.cs` | Y1/Y2: `Roll(runSeed, nodeId)` = seeded 50/50 aggressive/patient from its own FNV seed (no other RNG stream moves); `Pick(profiles, node, runSeed)` = the node's named profile, else the first of the rolled temperament. M5: same seed → Continue fights the same profile. |
| `Ai/NodeProfiles.cs` | `Of(yokai, all, fixtures)` = a yokai's own profiles (aggressive first), else fixtures; `WithNamed(nodeId, own, named, all)` appends a node's named profile (missing throws). Used by `HarnessContent.ProfilesForNode` and `FightScene.LoadNodeProfiles`. |
| `Ai/TanukiPressure.cs` | Y5: `TanukiPressure(Wins)`: `Steps` (0–3), `ReactionFrames(base)` = base − 1 per step (floor 1), `AggressionBonus` = steps × `AggressionPerWin` (**provisional 10**). Applied to every opponent but the apprentice (`FightScene.PressureFor`); recorded as `AiSetup.AggressionBonus`. |
| `Ai/AiHarness.cs` | Headless AI runner: `Run(newMatch, profile, P1Script, seed, ticks, reactionFrames?, aggressionBonus?)` → `Result` (rounds, decisions, anti-air response ticks, knockdowns, wake jumps, habit fired/covered, EX and burst counts, hash), `DecisionsCsv()`, `SummaryJson()`. Scripts Idle, Random, Jumper, Thrower. Driven by `tests/AiHarnessMain.cs`. |
