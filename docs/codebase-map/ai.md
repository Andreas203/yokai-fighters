# Ai: fight AI

`game/scripts/Ai/`, namespace `YokaiFighters.Ai`. Pure C#, deterministic, seeded `SimRng`. Y1/Y2/Y4/P6: P2 plays from a behaviour profile and sees the world only as `AiView` snapshots through a reaction-delay buffer; it never reads input. Replay compatibility: a new option draws nothing from the RNG at its off value, and new `AiSetup` fields are left out when default, so older recordings replay unchanged. Index: [README.md](README.md).

| File | What it is and its public surface |
|---|---|
| `Ai/AiView.cs` | `AiView.Capture(match)` = the **only** sim → AI bridge (P6): tick, phase, hitstop, per fighter `FighterView` (position, facing, state, stun left, airborne, health, `MaxHealth`, meter, `BurstUsed`, visible move id/frame/active window/connected, `MoveIsEx`) and `ProjectileView`s; `JumpPunishPct(i)`, `WakeUpFrames`, `BurstFrames`, `LightHitstop`. No input, parser, buffer or `Match` reference (a reflection test enforces it), so the AI cannot read a press before it shows. |
| `Ai/BehaviourProfile.cs` | Kind `profile` loader (`Parse`, `LoadFile`, `LoadDirectory`): reaction tier/frames, aggression bias, preferred range, `Habit` (when → do → chance_pct), behaviours, `tell_cover_pct`, `ExUse(ChancePct, KeepMeter)`, `BurstUse(ChancePct, MinComboHits, MaxHealthPct)` (null = never spend meter, E22). `guard_pct` → `GuardPct` (int?): strict 0–100, explicit null rejected, left out of the fingerprint when null. |
| (cont.) | `Observation` enum = the schema's on-screen list; `AiAction` (generic, `normal:<id>`, `special:<id>`, `special:copied` = `CopiedSpecial`), `IsMove` (normal/special/throw). `IsEvent`: every observation except neutral, the three ranges and `opponent_blocking` is an event (rolled once when it starts). `AiFightTiers.Of(node)` = the E22 fight tier (the harness and `FightScene.TierOf` use it). |
| `Ai/AiLoadout.cs` | The AI fighter's own kit: action → `FighterInput.Attack(slot)` / `Special(slot[, ex])` + frames, and the throw's raw buttons. `special:copied` → `Fighter.CopiedSlot` (the Tanuki); on any other fighter, or with no copy, it resolves to nothing and the AI skips it. `TryGetEx` (EX request + `ex.meter_cost`), `TryGetTotalFrames`, `TryGetExFrames`, `Missing(profile)` (callers throw on any; `special:copied` exempt), `IsScreenMoveOf(action, moveId)`, `CanDo(action)` (side-effect free). |
| (cont.) | `ThrowMoveId`, `ThrowSlot`, `ThrowRequest` = the throw as a direct slot request: a request while busy is ignored and buffers nothing, unlike the raw buttons, whose press edge buffers a normal. |
| `Ai/ProfileAi.cs` | The brain. `Next(AiView now)` stores the screen in a ring of `ReactionFrames` and decides from the oldest: something first shown on tick j changes output on tick j + ReactionFrames at the earliest (Y4, P6). Per tick: burst check, habit (+ `tell_cover_pct` may hide it), event behaviours (weight = percent per occurrence), then neutral: weighted pick (offence × (50 + aggression)/100, defence × (150 − aggression)/100) plus `SpacingWeight` 40 "walk to the band". Bands close < 250, mid < 600 units (proposed). Actions → short input plans; `Log`, `HabitPlanRunning`. |
| (cont.) | Habits: an event trigger rolls on its rising edge. YOK-177: a standing trigger (`at_close_range`, `opponent_blocking`, a range, `neutral`) rolls when it holds and none rolled in the last `StandingHabitRearmTicks` 60 view ticks (proposed); ctor `standingHabits` false = the old rule (never rolls), for pre-YOK-177 recordings. A fired habit is held until its own move shows fresh on screen (`HabitPress`). `self_got_up` pre-holds to the predicted wake tick. |
| (cont.) | It never rolls a habit over an unfinished held jump answer, and a seen jump is still answered over a running standing-habit plan. A throw habit presses `ThrowRequest` and checks its start by `ThrowMoveId`; old recordings and `LegacyOpponent` keep the raw buttons. A burst that interrupts a fired standing habit resumes it afterwards, with no new roll. |
| (cont.) | E22: ctor `tier` (`AiFightTier` Standard/Elder/Tanuki). The standard tier makes no meter rolls at all, so standard fights and replays are unchanged; `ex_use` (`MaybeEx`: own meter on screen ≥ cost + `keep_meter`) and `burst_use` roll only in elder and Tanuki fights. Burst is rolled only while the seen hitstun still runs at press time, then LP+MP+HP for 1 tick; no re-roll until its own press has shown. |
| (cont.) | Pre-emptive guard `GuardPct` (ctor → profile → `DefaultGuardPct` 0 = off): `RollGuard` makes no draw at 0; holds down-back while waiting in band and `GuardTicks` 10 after its own moves, re-reading `back` each tick (follows cross-ups). YOK-176: each fresh view showing `HitstopLeft > 0` from the plan's `CountFrom` on adds one guard tick (`ExtendGuard`), so the tail still covers `GuardTicks` free steps; a view after the guard ended adds nothing. |
| (cont.) | Jump punish (`JumpPunish`): one draw at `JumpPunishPct(Self)`, then a weighted pick among the answers `CanDo` allows; no performable answer = no draw, a second draw only with several answers. The answer is held until `FirstActionableTick` and the press window is capped at `MinInterruptTicks`, so an interrupted answer is never pressed twice from one roll. On a miss the other answers roll by weight; null rate = list-order weights. |
| `Ai/NodeTemperament.cs` | Y1/Y2: `Roll(runSeed, nodeId)` = seeded 50/50 aggressive/patient from its own FNV seed (run seed, tag "TEMP", node id), so no other RNG stream moves; `Pick(profiles, node, runSeed)` = the node's named profile (no roll), else the first of the rolled temperament, else 0. A debug-menu temperament still wins (E23). M5: the seed is saved, so Continue inside a node fights the same profile. |
| `Ai/NodeProfiles.cs` | `Of(yokai, all, fixtures)` = a yokai's own profiles (aggressive first), else fixtures; `WithNamed(nodeId, own, named, all)` appends a node's named profile found by id in `data/profiles/` (missing throws). The apprentice's profile has `yokai: "apprentice"`, so it is never in the Kitsune's list. Used by `HarnessContent.ProfilesForNode` and `FightScene.LoadNodeProfiles`. |
| `Ai/TanukiPressure.cs` | Y5: `TanukiPressure(Wins)`: `Steps` = wins clamped 0–`MaxWins` 3, `ReactionFrames(base)` = base − 1 per step (floor `MinReactionFrames` 1), `AggressionBonus` = steps × `AggressionPerWin` (**provisional 10**). `ProfileAi` `Aggression` = profile bias + bonus, clamped 0–100. Every opponent but the apprentice (`FightScene.PressureFor`); recorded as `AiSetup.AggressionBonus`, left out when 0. Tests `TanukiPressureTests`. |
| `Ai/AiHarness.cs` | Headless AI runner: `Run(newMatch, profile, P1Script, seed, ticks, reactionFrames?, aggressionBonus?)` → `Result` (rounds, decisions, anti-air response ticks, knockdowns, wake jumps, habit fired/covered, EX and burst counts, hash), `DecisionsCsv()`, `SummaryJson()`. Scripts Idle, Random, Jumper, Thrower. Driven by `tests/AiHarnessMain.cs`. |
