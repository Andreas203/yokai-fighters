# Fight: the fight scene and its presentation

`game/scripts/Fight/`, namespace `YokaiFighters.Fight`. Godot side of a fight: `scenes/fight.tscn` (`FightScene`, the scene to open for fight work and what tests, captures and `--fight` instance). Presentation reads the sim and never writes it; animation is stepped with `AnimationPlayer.Seek()` from the sim tick (F3). 200 units per metre, gameplay plane at Z = 0 (F4). Scene tree and editing notes: [project.md](project.md). Index: [README.md](README.md).

## FightScene partials

| File | What it is and its public surface |
|---|---|
| `Fight/FightScene.cs` | Owns `Match` + `FixedStepClock`; `_Process` runs the due ticks then `Render()`. `NewMatch(run, session)` = `NodeFight.NewMatch` (shared with the harness). `Opponent` (body, default "kitsune"), `Sources` (`KitSources.Repo`; tests swap `FixtureSources`), `LoadKit`, `LoadMoves`, `LoadSpecials`, `LoadAbilityPool()`, `DefaultScheme` (Kihon), `SchemeOf`/`SetScheme`/`ToggleScheme`. Every `Match.Step` goes through `StepSim`. `ExternalDrive` + `Step()` let tests drive it without clock or keyboard. `LoseCardFor(story, node, opponent)`: S3 lose card by yokai and row. |
| (cont.) | `Camera`, `CameraRig`, `Session`, `OwnsSession`, `NewSession(mapFile, seed, pool?, run?)`, `Node`. Elder twists: `Twists` (`data/twists/`, loaded once), `Twist` (this fight's, for the HUD), `TwistCard` (`Flow/TwistCard` intro `StoryCard` on entering an elder node; the fight waits behind it), `FirstMeeting` (set from `GameFlow.FirstMeeting`; decides the HUD callout). |
| `Fight/FightScene.Flow.cs` | Each fight is one node of the `RunSession`: win → `Session.WinFight` + binding card + `RewardScreen` → `CompleteNode` (`FinishNode`); loss → `LoseFight`. On its own the scene walks `demo-map.json`. `DemoStage` (Fighting/Binding/Reward/Complete/Lost), `CheckDuelOver()`, `RestartRun()`, `ResetFight()`, `LeaveForTitle()`, `RequestTitle()`/`TitleRequested`, `RunRestartRequested`, `PlayerScheme`, `P1Live()`, `Duels`, `OpponentName`/`OpponentYokai`, `LoadTrials()`, `LoadStory()`/`StoryDir`. Debug **F9** menu, `SetTemperament`, `--temperament=<t>`. |
| `Fight/FightScene.Ai.cs` | P2 = `ProfileAi` by default (`P2Input()` = `ai.Next(AiView.Capture(Match))`). `TierOf(node)` (E22), `TanukiWins` → `Pressure` (`PressureFor` exempts the apprentice), `LoadProfiles()`, `LoadNodeProfiles`, `RebuildAi()` (fresh delay buffer, `AiSeed` 27; throws via `AiSetupError` on a profile/kit mismatch), `StepWithAi(p1)`. Debug **F6** temperament, **F7** P2 AI/keyboard. |
| `Fight/FightScene.Models.cs` | `BuildModels()` instances both bodies with `FighterModel.Create` under `Fighters` at the `P1Spawn`/`P2Spawn` markers; one `FighterPresenter` per side (`FighterAnimSet.For`, `ForNode(Opponent, Node?.Yokai)`); `ObservePresentation()` after every step, `RenderModels()` from `Render`. Static `Catalog` (`data/clips`), `MoveClips`. `ShowModels`, debug **F10**, `ModelOf(i)`/`PresenterOf(i)`, `CameraFraming`. |
| (cont.) | The spawn markers set only the editor preview pose and the initial placement: `RenderModels` places every body from its sim position from the first frame, so moving a marker has no visible effect in game. `BuildModels` runs once per FightScene, so a self-walked run keeps the first node's bodies. |
| `Fight/FightScene.Stage.cs` | `BuildStage()` instances `StageContainer/Stage` from `NodeContext.Stage`, else the grove (`GroveScene`); pure `StageSceneFor(...)` falls back to `PlaceholderScene` when assets are missing or with `--stage=placeholder`. `StageRoot`, `StageKind`, `CameraDistance(config)`. Visual only. `BuildStage` runs once per FightScene, so a self-walked run keeps the first node's stage; hosted runs (GameFlow) build a new fight scene per node. |
| `Fight/FightScene.Pause.cs` | In-fight pause (`PauseLayer/Pause`, CanvasLayer 15). Esc / pad Start → `TryPause()` with `BuildPauseSummary()`. The tree is **not** paused: while `Paused`, `_Process` runs `PausedFrame()` (no tick, nothing recorded) and `Step()` is refused. `CanPause` (`PauseEnabled ?? !ExternalDrive`, Fighting only). `EndPause()` masks buttons not held right through (`ResumeMask`). `HeldBitsSource` test seam. |
| `Fight/FightScene.Replay.cs` | `Recorder` (`StartRecording()` on ready/reset/replace), `StepSim(p1, p2)` = the scene's only `Match.Step` + record (in a trial, `TrialRun.Step`). Debug **F8** `SaveReplay(path?)` → `user://replays/*.yfr`. |
| `Fight/FightScene.Trial.cs` | R7: `TrialStop` (the dojo with a running trial) → `NewTrialMatch()`, `Trial` (`TrialRun`), P2 AI off, **not recorded** (each attempt `Match.Reset`s with the trial's config and the dummy's input is scripted; recording would need the trial id + fingerprint, start offset and attempt boundaries in the header, and `Replayer` rebuilding the dummy from `TrialRun`); `CheckTrial()` → `Dojo.RecordAttempt`, `NextAttempt()`, `TrialDone`/`TrialFinished`. Greybox `TrialLayer/TrialPrompt`. |
| `Fight/FightScene.Practice.cs` | GDD 8 practice: `PracticeMode` (read once in `_Ready`: setting it on a running fight changes nothing), `InPractice` (= the scene has a `Dummy`), `SetUpPracticeRun()` (fresh run, never entered, no save point, no unlocks: provisional), `PracticeNode()` (a `dojo` node), `Dummy` (`PracticeDummy`), `ResetPractice()` on KO, `PracticeResets`. **F5** stance, **Backspace** / pad Back reset. `DebugOverlay` kept in every build here; no replay. |
| `Fight/FightScene.Tutorial.cs` | Y6 scene side: `TutorialAllowed` (host-set), `IsGuided(allowed, node)` (tier `apprentice`), `Tutorial`, `Coach`, `TutorialOptions`, `TutorialFinished`, `ObserveTutorial`, `SkipTutorialLesson()` (Tab / pad Back), `TutorialPromptText`. P2 = coach while a lesson needs it. |
| `Fight/FightScene.HitSparks.cs` | `SetUpHitSparks()` (`Presets` = `data/presets/`, bad folder → error + empty), `RenderHitSparks()`, `HitCues` (settable `IHitCueSink`), `LastHitCue`. |
