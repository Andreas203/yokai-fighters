# Goal agent notes

`tools/goal_agent/writer.py` (`MAP_FILE`) appends one entry here for each feature the goal agent writes, under the heading below. An entry is a note for the designer's review, not a map row: when the branch merges, move what it says into the area file that holds the code and delete the entry. The docs check reports a new script under `game/scripts/` until its area file has a row for it. Index: [README.md](README.md).

## Built by the goal agent (`tools/goal_agent/`)
Features written by the goal agent and accepted by its gates (build, tests, re-scan, code-critic, test-breaker). Each still needs the designer's review before it merges.
