# Flow: boot flow and screen routing

`game/scripts/Flow/`, namespace `YokaiFighters.Flow`. Main scene `scenes/boot.tscn` (`GameFlow`, never freed; `Menus` CanvasLayer 30 with `Title` = `ui/title_menu.tscn`, `ControlSelect` = `ui/start_screen.tscn`). Title → control select → map ⇄ fight, Title ↔ Settings, Title → Practice, Map or Fight → Title, Quit. A rest stop (a node scene under `Fight`) goes to the map on Esc / B before a choice and to the title from its pause menu (YOK-175). Menus cannot touch the sim: a node's scene is created only when the router reaches `Fight` and freed on the way back. Index: [README.md](README.md).
