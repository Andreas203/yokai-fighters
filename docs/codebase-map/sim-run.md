# Sim/Run: run state, map, run flow, stops

`game/scripts/Sim/Run/`, namespace `YokaiFighters.Sim`. Pure C#, no Godot, deterministic (seeded `SimRng`; pool lists sorted by file name). `GameFlow` (boot scene, never freed) holds the `RunSession`, so the run outlives every node's scene; scenes only call it. Every `StateHash()` mixes a new field only once it is set, so older runs and replays keep their hash. Index: [README.md](README.md).

Flow: `RunSession.Start(pool, graph, scenes, seed)` → `Reachable()` → `Enter(id)` → fight → `WinFight(health)` (R3 heal + A7 draft) or `LoseFight()` → pick → `CompleteNode()` → back to the map until `Ended`.

## Run state and rewards

| File | What it is and its public surface |
|---|---|
| `Sim/Run/RunState.cs` | Ryo's run: `Health` (C1 carry), slots A–D of `OwnedSpecial(Data, Level, Modifier, Borrowed, ModifierBorrowed)`, `Map` (`RunMap?`), `Coins` (R8). `NewRun(pool, map)` (starters Lv 1, A1; 1,000 health), `Equip` (A3 level up, A6 replaced slot loses levels), `LevelUp`/`CanLevelUp` (cap 3), `Attach`/`CanAttach` (A2), `AfterDuel(healthLeft, bound)` (R3: +50 capped), `SetHealth`, `AddCoins`/`CanAfford`/`TrySpend`/`RestoreCoins`, `Borrow`/`Release` (T5: never the last special), `CarryOverCandidates`, `MatchConfig(base)` + `ApplyTo`, `StateHash()`. |
| `Sim/Run/RewardTypes.cs` | Draft contract: `CardKind` (NewSpecial, Upgrade, Modifier), `CardView` (A12: `Plain` first, `Frames` behind the toggle; `NeedsTarget`), `CardTarget`, `RewardOffer`, `PickResult`, `IRewardDraft { Offer; Picked; Pick(cardIndex, target) }` (one pick; a failed pick changes nothing). |
| `Sim/Run/RewardDraft.cs` | `Build(run, pool, yokai, seed, elder, upgradeChoice)`: NEW (unlocked special of the beaten yokai, A8; rare only from an elder, A9), UPGRADE (A7, while something can level), MODIFIER (eligible target; player picks); refills from the pool. Frame text generated from before/after `MoveData` (`FrameDiff`); `Describe(effect)` via `Effects.Whole`. |
| `Sim/Run/ModifierData.cs` | Kind `modifier` (`ModifierLoader.Parse/LoadFile/LoadDirectory`): `Requires`, `Effects`, `FrameEffects` (`ModifierEffect(Effect, When)`), `ExCostEffects` + `ExCostFor`, `StartMask`, card. `AppliesTo(special)` via `SpecialData.HasProperty`. `ModifierLoader.Conditions` = accepted `when` values (schema `modifierCondition`). Applied generically in `SpecialData.Build` (A10). |
| `Sim/Run/AbilityPool.cs` | `Load(KitSources, modifiersDir)`, `LoadRepo(root)`, `LoadFixtures(root)`: starters = Ryo's kit; drafted specials = every non-starter in `data/moves/` of any source; modifiers from `data/modifiers/`; per-yokai fixture fill-in. Builds every modifier on every special at load; rejects duplicate ids. `WithUnlocks(ids)`, `IsAvailable(x)` = `!Locked || Unlocked.Contains(id)` (M1, A11; the one lock test for draft and shop). `Notes`. |
| `Sim/Run/CarryOver.cs` | M3, static. `MinRow` 6, `Level` 2. `Qualifies(RunEnd)`, `Best(run)` (T2/T3 ranking over `CarryOverCandidates`; borrowed ink never carries, R6), `FromRunEnd`, `NewRun(pool, carriedId, map, out dropped)` (carried special at Lv 2 in its slot, no modifier). **Provisional** (designer). Tests `CarryOverTests`. |
| `Sim/Run/Unlocks.cs` | M1, pure. `CountFor(RunEnd)`: beat Tanuki 4, lost at Tanuki 2, row ≥ 6 1, else 0. `new Unlocks(order)`, `Order`, `StillLocked`, `Award(end, unlocked)`, `FromData(pool, lockedCancelIds)` (**provisional** order: specials, modifiers, cancel rules), `WhyDropped(id)`. Tests `UnlockTests`, `UnlockEffectTests`. |
| `Sim/Run/CopyRule.cs` | T2–T4 from the run alone: `CopyRule.Target(run)` → `CopyTarget(Slot, Data, Level)` or null: highest level, no filter on move kind (T2), then most recently levelled, then lower slot (T3). `CopyTarget.MoveLevel` capped at `HighestUnevolvedLevel` 2, `Build(ex)` never takes a modifier (T4). Uses `RunState.LevelledOrder(slot)` / `RestoreLevelledOrder`. Locks nothing (T1 is `RunSession`). Tests `CopyRuleTests`. |

## Map

| File | What it is and its public surface |
|---|---|
| `Sim/Run/MapGraph.cs` | `MapNodeData(Id, Row, Type, Yokai?, Elder, Label?, Payload)` (`PayloadString`/`PayloadInt`), `MapRoute(From, To)`, `MapGraph(id, nodes, routes, types, name?)`: `Nodes`, `Routes`, `StartNodes`, `EndNodes`, `Rows`, `Node`/`Find`/`Has`, `Next`/`Previous`/`HasRoute`, `NodesInRow`, `Fingerprint`. The constructor validates (one `FormatException` listing every problem: duplicates, bad routes, unreachable nodes, dead ends). |
| `Sim/Run/NodeTypes.cs` | `INodeType { Id; Fight; Placeholder; Check(node) }`, `INodeTypeRegistry`, `NodeType` record, `NodeTypeRegistry.Default()` = `duel`, `elder`, `boss` (fights, need a `yokai`), `merchant`, `dojo`. Behaviour is looked up by type id in the owning system, never in `RunMap`. |
| `Sim/Run/MapLoader.cs` | `IMapSource { Load() }`, `FileMapSource(path)` / `.Default(mapDir)` (`default-map.json`), `MapLoader.Parse/LoadFile`: kind `run_map`, `schema_version` 1. |
| `Sim/Run/RunMap.cs` | Where Ryo is: `Current`, `Visited`, `InNode`, `Reachable()`, `CanSelect`, `Select(id)` / `Complete(id)` → `MapResult(Ok, Error)` (R1 one pick per row; a refused step changes nothing), `IsFinished`, `CurrentNode`, events `NodeEntered` (before the T1 lock: read `RunSession.LockedCopy` from `RunSession.NodeEntered`), `NodeCompleted`. `Snapshot()` / `Restore(graph, snapshot)`, `StateHash()`. `MapRules.R1Problems(graph)`. |

## Run flow and nodes

| File | What it is and its public surface |
|---|---|
| `Sim/Run/RunSession.cs` | One run: `RunSession(run, pool, scenes, seed, merchantChoice)`, `Start(...)` (resolves every node up front), `Run`, `Map`, `Reachable()`, `Enter(id)` (the only `RunMap.Select` caller; sets `Entered`, `Node`, `Merchant`, `Dojo`). |
| (cont.) | `WinFight(health)` → `RewardDraft?` (draft from `node.DraftYokai`, seed `Seed + Step`), `CompleteNode()` (refused while an offer or trial is open), `LoseFight()`, `Step`/`Steps`, `Ended` (`RunEnd(Outcome, RowReached, NodeId)`), `IsOver`, `NodePaid`, `CoinsWon`, `BoundYokai()`, `Trials`, `CopyLocked`/`LockedCopy` (T1: `Enter` of a `boss`-type node, `IsCopyLockNode`, locks once before `NodeEntered`; `Restore` throws when lock and walk disagree; tests `CopyLockTests`), `Restore(...)`, `StateHash()`. |
| (cont.) | Events `NodeEntered`, `NodeCompleted`, `RunEnded`. |
| `Sim/Run/NodeScenes.cs` | `NodeContext(NodeId, Type, Row, Yokai?, Elder, Fighter, Profile?, Tier, ReactionFrames, Binds, StandIn, Payload, Notes)` + init `Coins`, `Stage`, `Kit`, `PlaysAs`, `JumpPunishPct`; `MovesAndProfilesOf`, `DraftYokai`, `BindingName`. `NodeScene(Scene, Context)`, `INodeSceneResolver`, `NodeSceneTable` (`Default(mapDir)`, `LoadFile`, `Parse`; kind `node_scenes`; lookups most specific first: node → row → type → default). Tier frames per Y4. `StagePattern` = `validate_data.py` `STAGE_PATTERN`. Tests `DraftFromBeatenYokaiTests`. |
| `Sim/Run/NodeFight.cs` | `NodeFight.NewMatch(sources, run, session, opponent, scheme, log)`: the one fight builder (`FightScene.NewMatch`, `RunHarness`). Opponent kit via `Kit.LoadAs` with `MovesAndProfilesOf`, or `TanukiKit` for `copy_of_ryo`; tier sets `SimConfig.P2DamagePct` (`damage_dealt_pct`, Y4; `ScaleDamage` rounds down after counterhit and precision) and `P2JumpPunishPct`; elder twist applied. Tests `ApprenticeDamageTests`. |
| `Sim/Run/Merchant.cs` | R6 merchant stop: `MerchantChoice { None, Heal, Shop }`, `Choice`, `NodeId`, `Open`, `CanChoose`/`CanHeal`, `TakeHeal()` (+250 = 25% of max, capped), `Choose(Shop)`, `Restore(choice)` (no second heal), `Shop`. One choice per stop; a save must carry it. Tests `MerchantTests`. |
| `Sim/Run/MerchantShop.cs` | R6 shop, T5, no RNG. `Shelf`/`ShelfFor(run, pool, boundYokai)` (commons, A9; unlocked, A11; not starters, held, or from a bound yokai), `ModifierShelf`, `ModifierTargets(id)`. `Buy(id)` (50, borrowed ink, needs a free slot), `BuyModifier(id, slot)` (50, via `RunState.Attach`, A2), `Release(slot)` (40; not the last special, not a starter). `CanX`/`WhyNotX`; refusals change nothing. Shelf size, slot rules and several buys per stop are **proposed**. |
| `Sim/Run/Dojo.cs` | R7 dojo stop: `Choice` (`DojoChoice` None/Rest/Trial), `Rest()` (+30% capped), `Trials` → `DojoTrialOffer(Slot, Trial)`, `ChooseTrial(id)`, `RecordAttempt(landed)` (3 attempts; ends with +15% heal and a level-up when landed), `TrialRunning`, `TrialResult`, `Restore(choice)` (a trial is never restored, M5), `IsOpen`, `HashTag`. |
| `Sim/Run/TrialData.cs` | R7 trial data: `TrialLoader.Parse/LoadFile/LoadDirectory` → `TrialData` (`Id`, `Special`, `Prompt`, `Attempts` 3, `Distance`, `AttemptFrames`, `Dummy`, `Steps`, `Rules`). `TrialDummy(Action, Moves, Every)`, `TrialStep(Event, Move?, Count, Counter, DummyState, LandedWithin, Min/MaxDistance)` with `ComboHolds`, `Sample` (throws sampled at the grab), `DummyStateMet`, `DistanceMet`. Rejects Kata-only keys (K2) and impossible steps. Mirrors `trial.schema.json` and `validate_data.py`. Tests `TrialTests`. |
| `Sim/Run/TrialRun.cs` | One trial on a real `Match` (Ryo P1, dummy P2): `Config(base, trial)`, `Step(p1)` (scripted dummy input + `Match.Step` + goal check), `NextAttempt()`, `Attempt`, `AttemptTick`, `StepsMet`, `AttemptOver`, `Landed`, event `AttemptEnded`. `HeldInput(action, facing)` shared with practice. |
| `Sim/Run/PracticeDummy.cs` | GDD 8 practice dummy: `PracticeStance` Stand/Block/Crouch/CrouchBlock, `Next()`, `ActionOf(stance)`, `Input(dummy)` = `TrialRun.HeldInput`. No AI. |

Data: `data/map/default-map.json` (**proposed**, GDD 6.1 Figure 6, 9 rows, `boss-tanuki` last), `data/map/demo-map.json` (two-duel demo), `data/map/node-scenes.json` (**proposed**: scenes, tiers apprentice 30 / yokai 22 / elder 18 / tanuki 15 frames, coins, binds, stages, `plays_as`; `opponents.tanuki` has `kit` `copy_of_ryo`).
