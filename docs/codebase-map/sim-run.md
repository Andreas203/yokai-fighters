# Sim/Run: run state, map, run flow, stops

`game/scripts/Sim/Run/`, namespace `YokaiFighters.Sim`. Pure C#, no Godot, deterministic (seeded `SimRng`; pool lists sorted by file name). `GameFlow` (boot scene, never freed) holds the `RunSession`, so the run outlives every node's scene; scenes only call it. Every `StateHash()` mixes a new field only once it is set, so older runs and replays keep their hash. Index: [README.md](README.md).

Flow: `RunSession.Start(pool, graph, scenes, seed)` → `Reachable()` → `Enter(id)` → fight → `WinFight(health)` (R3 heal + A7 draft) or `LoseFight()` → pick → `CompleteNode()` → back to the map until `Ended`.

## Run flow and nodes

| File | What it is and its public surface |
|---|---|
| `Sim/Run/RunSession.cs` | One run: `RunSession(run, pool, scenes, seed, merchantChoice)`, `Start(pool, graph, scenes, seed)` (resolves every node up front, so a node the resolver cannot place fails at start), `Run`, `Map`, `Reachable()`, `Enter(id)` → `MapResult` (the only `RunMap.Select` caller; sets `Entered` = `NodeScene`, `Node`, `Merchant`, `Dojo`), `Step`/`Steps`, `Ended` (`RunEnd(Outcome, RowReached, NodeId)`), `IsOver`, `BoundYokai()`, `Trials`, `StateHash()`. |
| (cont.) | `WinFight(health)` → `RewardDraft?`: R3 `AfterDuel(health, node.Binds)`, coins once (R8), the A7 draft from `node.DraftYokai` (never the stand-in body), seed `Seed + Step`, `elderId` = the elder's `BindingName` (YOK-186), when the node binds and is not the last. `NodePaid` (saved): a win reported on a paid node changes nothing (R3, R8). `CoinsWon` = that node's payout until it completes (not saved). `CompleteNode()` refused while an offer is unpicked or a trial runs; last node → `Ended` = Won. `LoseFight()` → Lost. |
| (cont.) | **Provisional (YOK-186, designer):** an elder node that pays no coins (R8: the row-8 elder) whose draft holds no `Rare` card pays `R8FallbackCoins()` (the most any elder node of the map pays: the row-5 elder's 50), so the reward is never empty. |
| (cont.) | Events `NodeEntered(NodeContext)`, `NodeCompleted(NodeContext)`, `RunEnded(RunEnd)`; on the last node `NodeCompleted` is raised before `RunEnded`, with `IsOver` already true. Session state is plain data (`Seed`, `RunState`, `RunMap.Snapshot()`, `Ended`, lock, `NodePaid`, `Merchant.Choice`, `Dojo.Choice`); `Restore(run, pool, scenes, seed, copyLocked, lockedCopy, merchantChoice = None, nodePaid = false)` puts a saved one back. |
| (cont.) | **Copy lock (T1):** `Enter` of a node whose type is `NodeTypeRegistry.Boss` (`IsCopyLockNode(NodeContext)`: the node type from map data, never a yokai or node id) sets `CopyLocked` and `LockedCopy = CopyRule.Target(Run)` before `NodeEntered` is raised. Once per run; a refused `Enter` locks nothing. `LockedCopy` is a snapshot: later slot changes never reach it (null only when no slot held a special). |
| (cont.) | There is no setter for the lock on a live session: only `Enter` takes it, and restored walks never recompute it from the slots. The plain constructor refuses (`ArgumentException`) a walk that has already entered a boss node; `Restore` throws when lock and walk disagree or the copy is not a target of the pool's own data. The lock is mixed into `StateHash` only once `CopyLocked`. Tests `CopyLockTests`. |
| `Sim/Run/NodeScenes.cs` | `NodeContext(NodeId, Type, Row, Yokai?, Elder, Fighter, Profile?, Tier, ReactionFrames, Binds, StandIn, Payload, Notes)` + init `Coins`, `Stage`, `Kit`, `PlaysAs`, `JumpPunishPct`; `MovesAndProfilesOf`, `DraftYokai`, `BindingName`. `NodeScene(Scene, Context)`, `INodeSceneResolver`, `NodeSceneTable` (`Default(mapDir)`, `LoadFile`, `Parse`; kind `node_scenes`; lookups most specific first: node → row → type → default). Tier frames per Y4. `StagePattern` = `validate_data.py` `STAGE_PATTERN`. Tests `DraftFromBeatenYokaiTests`. |
| `Sim/Run/NodeFight.cs` | `NodeFight.NewMatch(sources, run, session, opponent, scheme, log)`: the one fight builder (`FightScene.NewMatch`, `RunHarness`). Opponent kit via `Kit.LoadAs` with `MovesAndProfilesOf`, or `TanukiKit` for `copy_of_ryo`; tier sets `SimConfig.P2DamagePct` (`damage_dealt_pct`, Y4; `ScaleDamage` rounds down after counterhit and precision) and `P2JumpPunishPct`; elder twist applied. Tests `ApprenticeDamageTests`. |
| `Sim/Run/Merchant.cs` | R6 merchant stop: `MerchantChoice { None, Heal, Shop }`, `Choice`, `NodeId`, `Open`, `CanChoose`/`CanHeal`, `TakeHeal()` (+250 = 25% of max, capped), `Choose(Shop)`, `Restore(choice)` (no second heal), `Shop`. One choice per stop; a save must carry it. Tests `MerchantTests`. |
| `Sim/Run/MerchantShop.cs` | R6 shop, T5, no RNG. `Shelf`/`ShelfFor(run, pool, boundYokai)` (commons, A9; unlocked, A11; not starters, held, or from a bound yokai), `ModifierShelf`, `ModifierTargets(id)`. `Buy(id)` (50, borrowed ink, needs a free slot), `BuyModifier(id, slot)` (50, via `RunState.Attach`, A2), `Release(slot)` (40; not the last special, not a starter). `CanX`/`WhyNotX`; refusals change nothing. Shelf size, slot rules and several buys per stop are **proposed**. |
| `Sim/Run/Dojo.cs` | R7 dojo stop: `Choice` (`DojoChoice` None/Rest/Trial), `Healed`, `CanRest`, `Rest()` (+300 = 30% of max, capped; the one choice, a second call refused), `Rested(health)`, `Trials` → `DojoTrialOffer(Slot, Trial)` (owned, levellable specials with a trial; provisional), `ChooseTrial(id)`, `RecordAttempt(landed)` (3 attempts; ends with +15% heal and a level-up when landed), `TrialRunning`, `TrialResult`, `HashTag`. Tests `DojoTests`, `DojoTrialTests`. |
| (cont.) | **A save must write `Dojo.Choice`**: a session rebuilt inside a dojo opens the stop unspent until `Restore(choice)` (no heal; only on a stop with no choice yet). A trial is never restored (`Restore(Trial)` throws, M5). `IsOpen` is checked by reference (`RunSession.IsOpenDojo`): a `Dojo` kept past `CompleteNode` or `LoseFight` refuses `Rest` and `Restore` and changes nothing; one built on its own is always open. |
| `Sim/Run/TrialData.cs` | R7 trial data: `TrialLoader.Parse/LoadFile/LoadDirectory` → `TrialData` (`Id`, `Special`, `Prompt`, `Attempts` 3, `Distance`, `AttemptFrames`, `Dummy`, `Steps`, `Rules`). `TrialDummy(Action, Moves, Every)`, `TrialStep(Event, Move?, Count, Counter, DummyState, LandedWithin, Min/MaxDistance)` with `ComboHolds`, `Sample` (throws sampled at the grab), `DummyStateMet`, `DistanceMet`. Rejects Kata-only keys (K2) and impossible steps. Mirrors `trial.schema.json` and `validate_data.py`. Tests `TrialTests`. |
| `Sim/Run/TrialRun.cs` | One trial on a real `Match` (Ryo P1, dummy P2): `Config(base, trial)`, `Step(p1)` (scripted dummy input + `Match.Step` + goal check), `NextAttempt()`, `Attempt`, `AttemptTick`, `StepsMet`, `AttemptOver`, `Landed`, event `AttemptEnded`. `HeldInput(action, facing)` shared with practice. |
| `Sim/Run/PracticeDummy.cs` | GDD 8 practice dummy: `PracticeStance` Stand/Block/Crouch/CrouchBlock, `Next()`, `ActionOf(stance)`, `Input(dummy)` = `TrialRun.HeldInput`. No AI. |

Data: `data/map/default-map.json` (**proposed**, GDD 6.1 Figure 6, 9 rows, `boss-tanuki` last), `data/map/demo-map.json` (two-duel demo), `data/map/node-scenes.json` (**proposed**: scenes, tiers apprentice 30 / yokai 22 / elder 18 / tanuki 15 frames, coins, binds, stages, `plays_as`; `opponents.tanuki` has `kit` `copy_of_ryo`).
