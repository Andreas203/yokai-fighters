# Documentation index

Every document in the repo, what it is for and who keeps it. If you are looking for something, start here. If you are about to write a new document, read [`process/change-tracking.md`](process/change-tracking.md) first: most changes belong in a Linear ticket, one line in an existing log or the PR, not in a new file. `tools/check_docs.py` (CI) fails on dead links and on Markdown outside the homes below.
