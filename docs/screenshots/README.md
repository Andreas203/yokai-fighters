# Screenshots

Captures of the running game. One folder says what is current; the other holds old ticket shots waiting for a decision.

| Folder | What it holds |
|---|---|
| `current/` | The latest capture of each in-game screen: start, HUD, lose, demo complete and the four reward steps (1080p, plus two 720p checks). |
| `current/menus/` | The title, pause, settings and move-list mockups from `scenes/ui/menu_mockups.tscn`. Placeholder art, not wired into the boot. |
| `current/stage/` | Bamboo grove at dusk: fight, both corners, mid-stage, max separation, Kitsune close-up. |
| `current/fighters/` | Ryo and Kitsune on active frames with the hitbox overlay, and the tail close-up. |
| `review/` | Development screenshots from Linear tickets, superseded or evidence only. See `review/README.md`; the designer decides what stays. |

The designs these screens are being rebuilt towards are in `docs/design/screens/`, not here.

## Rules
- A new capture of a screen overwrites its file in `current/`. No per-ticket folders.
- Before/after evidence for a ticket goes in the PR, not in the repo.
- Capture tools and their arguments are listed in `docs/codebase-map.md`.
