# UI review: concepts vs game (2026-10-15)

For the **ui-designer**. Each concept in `docs/design/screens/` compared against the latest capture in `docs/screenshots/current/` (captured 2026-10-11 with the YOK-75 merge, `4d9a064`). The game was not re-run for this review, so re-capture before and after each fix.

Screens with no concept, or not built yet, are in `needs-final-ui.md`.

## How to use this
- **Fix** items are layout or behaviour bugs: build-and-test loop, capture at 1920x1080 and 1280x720, then Code Critic → Test Breaker → designer review.
- **Designer decision** items are not yours to resolve. Leave them as they are and list them in your PR as open.
- **Deliberate** items are recorded in `docs/codebase-map.md` as intended differences. Don't "fix" them.

## Per screen

### Title — `title.png` vs `menus/title.png` (`title_menu.tscn`)
Close match.
- Deliberate: the "Choose your path." tagline and its ink rule are replaced by router reasons.

### Control select — `control-select.png` vs `start.png` (`start_screen.tscn`)
- **Fix:** the Kihon description runs into the row's right border ("damage." touches or clips it). Add right padding, or wrap the text.
- **Fix:** the selected row has a black box *and* a red brush frame. In the concept the brush band replaces the box.
- **Fix:** the radio markers are small text bullets (`○` / `●`). The concept uses large drawn radio circles with a red filled dot.
- **Fix:** the empty ink rule under the rows floats in a large gap. Tighten the vertical rhythm so Start Game sits closer, as in the concept.
- Deliberate: no "Beat the Kitsune to bind her…" line, the extra "Controls reference" button, and the K1 copy wording.

### Fight HUD — `hud.png` vs `hud_fight.png` (`hud.tscn`, `FightHud.cs`)
- Deliberate: no paper plates behind the bars (YOK-75).
- **Fix:** the portraits are much smaller than in the concept. Ryo's portrait should match the height of the name, health bar and meter block.
- **Designer decision:** the `AGGRESSIVE` temperament label under the Kitsune bar isn't in the concept. Ask whether it stays in release builds or becomes debug-only.

### Pause — `pause.png` vs `menus/pause.png` (`pause_menu.tscn`)
- **Fix:** the fight HUD shows through: the Kitsune health bar and name overlap the top of the Current Run panel. Hide the HUD, or dim it under the panel, while paused.
- **Fix:** Ryo's health bar has no grey track for the missing health. The red fill ends in empty paper. Add the track as in the concept and the HUD.
- **Fix:** "Quit to title" overlaps the ink-cloud and blossom ornament in the bottom-left corner. Move the ornament down or the menu up.
- **Fix:** the concept's red brush underline under the heading is missing, as is the vertical diamond rail beside the menu items.
- **Fix:** the Foxfire row wraps onto two lines ("Foxfire · Lv 1" / "Will-o'-wisp"), unlike the other rows. Put the modifier on the same line, or give every row the same two-line layout.
- OK: the fourth row, "D Empty", is correct for the game (four slots).

### Pause confirm — `pause-confirm.png` vs `menus/pause_confirm.png`
- **Fix:** Cancel is a filled pink box. The concept uses an outlined ghost button, with the brush reserved for Restart.
- **Fix:** same HUD bleed-through as Pause (the Kitsune bar is visible top right).
- Copy differs ("This run ends here and a new one begins." vs "Your current run will be lost.") and should come from data. Not a layout issue.

### Settings, sound tab — `settings.png` vs `menus/settings_sound.png` (`settings_panel.tscn`)
- **Fix:** the slider fill is dark maroon on black, so contrast is low. The concept uses a bright shrine red (#B5332B) fill on an ink track.
- **Fix:** the sliders are short because the Preview column takes the width. Rebalance so the sliders read as the main control.
- **Fix:** the sheet covers the moon. The concept drops the sheet top so the moon and torii stay visible.
- Deliberate: the Preview buttons and "Mute all".

### Reward — `reward.png` vs `reward_cards.png` (`reward_screen.tscn`, `reward_card.tscn`)
- **Fix:** card body text has no left padding on the selected card; Foxfire's text touches the border. Use the same inner padding on all three cards in every state.
- **Fix:** header rows don't line up. The selected card's title sits higher than the other two, and the subtitle ("Kitsune - special") is pushed far below the title. The concept puts the letter badge, title and subtitle in one tight block.
- **Fix:** the art is a boxed rectangle inside the card. The concept bleeds it edge to edge behind the ink.
- **Fix:** a large empty area at the bottom of every card, while "Pick the special to carry it" is pinned to the bottom edge in blue. Follow the concept: put it under the description in ink colour.
- **Fix:** the "TAB Frame data: off" chip hangs off the bottom of the paper. The concept keeps it inside the sheet, bottom left.
- Copy: "3 talismans" vs "three talismans".

### Modifier target — `modifier-target.png` vs `reward_target.png` (`target_card.tscn`)
- **Fix (priority):** the slots don't use the diamond move icons. Spirit Wave shows the reward illustration, Rising Talisman shows the letter **"R"**, and empty slots show a "+" square. The pause menu already draws diamond icons for all of these moves, so reuse them here, with a grey "+" diamond for empty slots.
- **Fix:** disabled-slot text (Rising Talisman, Empty) has too little contrast on the grey card. Keep it readable, as in the concept.
- **Fix:** the red ▶ selection arrow left of the focused card is missing.
- **Fix:** large empty gap between the description line and the cards. Move the cards up.
- **Fix:** "Will-o'-wisp:" should be shrine red, as in the concept, with the effect text in ink.

### Story card — `story-card.png` vs `reward_binding.png` (`story_card.tscn`)
Close match.
- **Fix:** the binding line wraps and leaves "free." alone on the second line. Widen the text area, or step the font down, so the line fits on one line or splits evenly.
- Deliberate: the round blank seal (the concept has a square tomoe stamp) and the S3 copy.

### Defeat — `defeat.png` vs `hud_lose.png` (`lose_screen.tscn`)
- **Fix:** the "ENTER Restart" chip crowds the bottom edge of the paper. Give it a margin, or move it to the screen footer as on the other screens.
- **Fix:** the mask should be pinned over the top edge of the paper (half on, half off), as in the concept, not sitting inside it.
- X1 applies (focus outline on Restart).
- Deliberate: drawn over the dimmed live stage rather than the night backdrop; the longer story text.
- **Designer decision:** the dimmed HUD is still readable behind the card. Should results hide the HUD completely?

### Demo complete — `demo-complete.png` vs `demo_complete.png` (`demo_complete.tscn`)
- **Fix:** the heading is centred over two lines. The concept left-aligns it, matching the body column.
- **Fix:** same chip-crowding issue as Defeat.
- X1 applies. Same deliberate backdrop and same HUD-visibility decision as Defeat.

## Screens with captures but no concept (bugs only)

### Settings, controls tab — `menus/settings_controls.png`
- **Fix:** the CONTROL SCHEME label collides with the Controls tab's red underline.
- **Fix:** the last visible table row is cut in half at the scroll edge. Size the viewport to a whole number of 60px rows, or add a fade.
- **Fix:** the footer shows `LEFT / RIGHT Adjust` on this tab, where nothing adjusts. Footer hints should follow the active tab.

### Move list — `menus/move_list.png` (`move_list_panel.tscn`)
- **Fix:** special-card text has no left padding and touches the card border; descriptions overflow the bottom border ("screen.", "jumps.").
- **Fix:** the base-kit table's bottom row is cut mid-line at the scroll edge.
- **Fix:** the input column wraps awkwardly ("Up, up-forward, up-" / "back"). Widen the column or shorten the copy.
