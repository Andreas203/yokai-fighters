With the current wrong value of 3 and a Lv 3 `probe-evolving`, it passes while the copy is built with the evolution. It does not pin the T4 behaviour on its own. → Assert the literal expected level, `Assert.Equal(2, t.MoveLevel, ...)`, so the test fails if the constant drifts.
  - [test-breaker, advisory] author tests (tests): CopyRuleTests.CopyOfAnEvolvedSpecialHasNoEvolution asserts t.MoveLevel equals CopyRule.HighestUnevolvedLevel, which restates the code (the constant is 3, though the comment and A4 say Lv 2 is the highest unevolved level), so that line cannot fail.
